# JobNest

**JobNest** is a role-based job portal platform with separate functionalities for **Admin** and **Employer** users. Admins have full control over the platform, while employers can manage their job postings and profiles. The platform is built with **React**, **TypeScript**, **JWT authentication**, **MongoDB**, and **Express.js**, using modern tools like **TanStack Query**, **React Hook Form**, and **Axios** for seamless API handling.

---

## Features

### Admin Features
- **View Dashboard** with metrics and statistics.
- **Manage Job Listings**:
  - Approve or reject jobs.
  - Filter, sort, and paginate job listings.
- **Manage Users**:
  - Create, view, edit, and delete users.
- **Manage Profile**:
  - View and edit own profile.

### Employer Features
- **View Dashboard** with job metrics.
- **Manage Job Listings**:
  - Post new jobs.
  - View job details.
  - Filter, sort, and paginate job listings.
- **Manage Profile**:
  - View and edit own profile.

---

## Tech Stack

### Frontend
- **React + TypeScript** – Robust, type-safe frontend.
- **TanStack Query** – Data fetching, caching, and synchronization.
- **React Hook Form** – Form handling and validation.
- **Axios** – API requests and HTTP client.
- **JWT Authentication** – Secure login and protected routes.

### Backend
- **Express.js + TypeScript** – REST API backend with type safety.
- **MongoDB + Mongoose** – NoSQL database for storing users, jobs, and roles.
- **JWT Authentication** – User sessions and access control.
- **Role-based Authorization** – Separate admin and employer routes.
